# Feliz Shoes bot

## Ishga tushirish
1. @BotFather → /newbot → token oling.
2. @userinfobot dan o'z ID raqamingizni oling.
3. `.env.example` ni `.env` deb nomlab, BOT_TOKEN va OWNER_ID ni yozing.
4. `pip install -r requirements.txt`
5. `python bot.py`

Botga kirib /start, keyin «⚙️ Admin panel» → «⚙️ Sozlamalar» → username va telefonni kiriting.
